# 📊 Outputs

This folder contains the HTML outputs generated from the **Retail Sales ETL & SQL Analytics** project.

The outputs provide evidence of the ETL process, database normalization, and the results of the five SQL business queries.

## 📁 Contents

- **ETL Validation** — Row counts confirming successful data loading and transformation.
- **Business Query Results** — Results from five SQL business questions covering revenue, customers, monthly sales, products, and profitability.
- **Sample Table Outputs** — Sample records from the normalized `Customers`, `Products`, `Orders`, and `Order_Details` tables.

## 🔎 Business Query Outputs

The five business-query files are numbered to correspond directly with **Business Query 1–5** in the main SQL script, making it easy to trace each analysis from **SQL query → HTML output → business insight**.

> **Purpose:** Provide transparent and reproducible evidence of the SQL transformations, database structure, and analytical results produced by the project.
